# 📁 02. Условные конструкции (Conditions)

Здесь находятся задачи на ветвление логики программы:
- Операторы `if`, `else`, `elif`
- Логические операторы: `and`, `or`, `not`
- Вложенные условия
- Подготовка и тренировка к экзамену по теме "Условия"

*Научилась писать программы, которые принимают решения на основе входных данных.*
