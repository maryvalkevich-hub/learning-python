# 📁 04. Работа со строками (Strings)

Самая объемная и интересная папка! Здесь собраны задачи по:
- Срезам строк (slicing): `[start:stop:step]`, реверс `[::-1]`
- Методам строк: `.lower()`, `.upper()`, `.find()`, `.replace()`, `.isdigit()` и др.
- Форматированию: f-строки (`f"{}"`), метод `.format()`
- Кодировке: функции `ord()` и `chr()`, таблица Unicode
- Лексикографическому сравнению строк

*Научилась профессионально обрабатывать, форматировать и анализировать текстовые данные.*
