# 📁 01. Основы Python (Basics)

В этой папке собраны задачи по фундаментальным темам Python:
- Переменные и типы данных
- Функции ввода и вывода (`input()`, `print()`)
- Базовые математические операции
- Встроенные функции: `min()`, `max()`, `abs()`
- Работа с модулем `math` (`sqrt`, `ceil`, `floor` и др.)

*Этот модуль заложил основу для понимания синтаксиса и логики языка.*
